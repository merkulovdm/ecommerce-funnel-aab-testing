# Анализ воронки и A/A/B тестирование

Выявление точек потерь на пути пользователя к покупке и проверка однородности экспериментальных групп перед A/B тестом.

## Контекст

E-commerce платформа не понимала, на каком этапе воронки теряется большинство пользователей и даёт ли редизайн UI реальный прирост конверсии. Перед измерением эффекта эксперимента необходимо было убедиться в корректности рандомизации через A/A тест.

## Результаты

| Шаг воронки | Конверсия |
|---|---|
| Просмотр → Корзина | 28.5% |
| Корзина → Покупка | 34.9% |
| **Просмотр → Покупка (сквозная)** | **~10%** |

- **A/A тест:** статистически значимых различий между контрольными группами нет (p = 0.059) — рандомизация корректна
- **A/B тест:** экспериментальный вариант UI не дал значимого прироста конверсии (p > 0.05)
- Наибольшие потери — на переходе `просмотр → корзина`: здесь теряется ~70% пользователей

## Рекомендации

1. **Приоритет — просмотр → корзина:** улучшить карточки товаров, добавить рейтинги и отзывы, проработать ценовое восприятие
2. **Вторично — корзина → покупка:** упростить оформление заказа, добавить способы оплаты, убрать обязательную регистрацию

## Методология

- Анализ воронки (уникальные пользователи на каждом шаге, пошаговая и сквозная конверсия)
- A/A/B дизайн эксперимента со случайным распределением пользователей по группам
- Двусторонний z-тест для двух пропорций (реализован через `scipy.stats.norm`)
- Период: Q1 2025 — полный квартал с равномерным охватом групп
